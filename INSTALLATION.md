# Installation and update verification

> **Not released.** There is currently no approved public Windows installer or downloadable in-app update. Follow these instructions only after a verified, explicitly approved release is published.

## When a public release becomes available

1. Open the official [GitHub Releases page](https://github.com/DanologyUK/Ring-Windows-Notifier/releases). Confirm the exact version, tag and release notes match.
2. For the current planned Ed25519 **installer-only** publication profile, the three version-matched assets are:
   - `Ring-Windows-Notifier-Setup-VERSION-x64.exe`
   - `RELEASE-MANIFEST-vVERSION.json`
   - `RELEASE-MANIFEST-vVERSION.json.sig`
3. Check the downloaded EXE's SHA-256 in Windows PowerShell:
   ```powershell
   Get-FileHash -Algorithm SHA256 -LiteralPath "C:\Path\To\Ring-Windows-Notifier-Setup-VERSION-x64.exe"
   ```
   Compare it against the manifest's exact installer checksum. **Stop if the values differ.** A checksum copied from the same download page alone does not authenticate the publisher; the app's trusted public key must independently authenticate the detached Ed25519 signature over the manifest.
4. The Ed25519 signature authenticates the release manifest, **not the Windows EXE with Authenticode**. If release notes claim Windows code signing, independently check the Windows Authenticode publisher and certificate. Don't bypass antivirus, Windows SmartScreen or other security warnings to force installation.
5. Read the version's Windows requirements and known issues. An approved machine-wide Setup should install program files into `C:\Program Files\Ring Windows Notifier`. Application settings and saved sign-in material live separately in the user's AppData; that is not an extra program installation.
6. If you have a backup-restored or older installation, follow the release's documented supervised migration instructions. Do **not** uninstall an existing working copy, delete private configuration files or remove an update receipt simply to bypass a safety check.

Never download an EXE from GitHub comments, issue attachments, unofficial mirrors or private CI artifacts.

GitHub's autogenerated “Source code (zip)” is **not** a Windows installer or an in-app update package.

## Updates

The planned public updater will discover versions using GitHub Release metadata without requiring a GitHub account. Downloading and installing must be separately consented to, with exact content verification, safe handoff, restart evidence and recovery. It is **not active on the public channel yet**.

Consult the [public beta release gate](PUBLIC-BETA-RELEASE-GATE.md) for the release engineering and acceptance checklist.

Ring Windows Notifier is independent and unofficial; it is not a guaranteed alarm or emergency-monitoring service.
